# todo-list-js
# 1. 프로젝트 제목및 간단 소개
이 프로젝트는 나만의 to-do 리스트 만들기 라는 제목으로, html로 to-do 리스트를 만들어 할일 목록을 만들고 수정 및 삭제하여 활용 할 수 있도록 만들었습니다.
또한 완료한 리스트는 체크 표시를 통해 구분할 수 있도록 만들었습니다.
# 2. 구현한 주요 기능
<li>1.우선 할일을 입력하여 추가 버튼을 누르면 todoArray에 데이터가 추가되고 화면에 즉시 할일 리스트가 생성됩니다.
<li>  아무것도 입력하지 않고 추가를 누르면 "글자를 입력하세요"라고 노출되도록 만들었습니다.
<li>2. 삭제 버튼을 누르면, 해당 항목의 고유 위치를 찾아 배열에서 제거하고 즉시 삭제된걸을 반영합니다.
<li>3.수정을 누르면 텍스트가 표시되던 공간을 기존 내용이 입력된 input 창으로 동적 전환되어 바로 수정할 수 있습니다.
<li>4.완료 버튼을 누르면 데이터의 true/false 값이 반전됩니다. 조건문을 활용하여 check.png 이미지를 주입시켜 체크 이미지를 표시하도록 구현하였습니다.
<li>5. 웹 브라우저를 새로고침하거나 완전히 종료했다가 다시 진입해도 기존에 작성했던 할 일 목록과 완료 상태가 그대로 유지되도록 하였습니다.
    데이터를 브라우저에 영구 저장하기 위해 JSON.stringify()와 JSON.parse()를 활용하여 만들었습니다.
# 3. 적용된 자바스크립트 핵심 기술
<li>1.단순 텍스트 저장이 아닌 id, text, checked, isEdit 구조의 객체 배열로 설계하여 데이터마다 고유 id와 상태를(완료,수정 여부)만들어 할일이 중복되거나 많아도 데이터가 꼬이지 않도록 관리하도록 만들었습니다.
<li>2.데이터(배열)와 화면(HTML)을 일치시키기 위해 화면 출력을 전담하는 render() 함수를 독립적으로 분리했습니다.
<li>3.배열 데이터가 바뀔 때마다 for 반복문과 백틱을 이용해 '<li>' 태그를 새로 구성한 후, ul.innerHTML을 통해 화면을 최신화하여 보여주도록 했습니다.
<li>4.if-else 조건문을 활용하여 데이터 상태의 따라 화면이 변하도록 구현하였습니다.
<li>4-1.isEdit 상태가 true면 일반 글자 대신 input 창을 띄워 수정할 수 있도록 만들었고, checked 상태가 true면 check.png를 표시하여 완료표시를 보여주도록 만들었습니다.
<li>6.브라우저를 새로고침 하거나 꺼놔도 데이터가 유지되도록 localstorage를 사용했습니다.
<li>7.문자열만 저장가능한 저장소 특성을 극복하기 위해 저장할땐 JSON.stringify() 와 JSON.parse()를 통해 데이터를 문자열로 변환하여 사용 할수 있도록 만들었습니다.
